## 🌍 多语言支持

### 支持的语言代码

| 语言 | 代码 | 文字方向 | 特殊处理 |
|------|------|---------|---------|
| 中文 | `zh-CN` 或 `zh` | LTR | - |
| 蒙古语 | `mn` | LTR | 西里尔字母 |
| 藏语 | `bo` 或 `bo-CN` | LTR | ⚠️ 竖排文字 |
| 维吾尔语 | `ug` 或 `ug-CN` | **RTL** | ⚠️ 从右到左 |
| 哈萨克语 | `kk` | **RTL** | ⚠️ 从右到左 |
| 朝鲜语 | `ko` | LTR | - |

### 前端处理方案

```javascript
// 1. 登录后获取语言配置
const i18nConfig = loginResponse.data.i18nConfig;

// 2. 根据direction设置CSS
if (i18nConfig.direction === 'rtl') {
  document.body.setAttribute('dir', 'rtl');
  // 或使用CSS
  document.body.style.direction = 'rtl';
}

// 3. 处理竖排文字（藏语）
if (i18nConfig.verticalWriting) {
  document.body.style.writingMode = 'vertical-rl';
}

// 4. 切换语言
async function switchLanguage(languageType) {
  await fetch('/api/user/me/language?languageType=' + languageType, {
    method: 'PUT',
    headers: {
      'Authorization': 'Bearer ' + token
    }
  });
  
  // 重新加载数据
  reloadPageData();
}
```

## ⚠️ 重要注意事项

### 1. Token管理

```javascript
// ✅ 正确做法：Token即将过期时刷新
const TOKEN_EXPIRE_TIME = 8 * 60 * 60 * 1000;  // 8小时
const REFRESH_BEFORE = 30 * 60 * 1000;  // 提前30分钟刷新

setInterval(async () => {
  const loginTime = localStorage.getItem('loginTime');
  if (Date.now() - loginTime > TOKEN_EXPIRE_TIME - REFRESH_BEFORE) {
    // 刷新token
    const response = await fetch('/api/user/refresh', {
      method: 'POST',
      headers: { 'Authorization': 'Bearer ' + oldToken }
    });
    const newToken = response.data.token;
    localStorage.setItem('token', newToken);
  }
}, 60000);  // 每分钟检查一次
```

### 2. 错误处理

```javascript
// 统一错误处理
async function apiRequest(url, options) {
  const response = await fetch(url, options);
  const data = await response.json();
  
  // 根据HTTP状态码处理
  if (!response.ok) {
    switch (response.status) {
      case 400:
        alert('请求参数错误：' + data.message);
        break;
      case 401:
        alert('未登录或token已过期');
        window.location.href = '/login';
        break;
      case 403:
        alert('权限不足：' + data.message);
        break;
      case 404:
        alert('资源不存在');
        break;
      case 500:
        alert('服务器错误，请稍后重试');
        break;
    }
    throw new Error(data.message);
  }
  
  return data;
}
```

### 3. 文件上传

```javascript
// ✅ 正确的文件上传方式
const uploadFile = async (file, userId, category) => {
  const formData = new FormData();
  formData.append('file', file);
  formData.append('uploadUserId', userId);
  formData.append('fileCategory', category);
  // relatedRecordId 是可选的，如果关联到申请记录才需要
  
  const response = await fetch('/api/file/upload', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer ' + token
      // ⚠️ 注意：不要设置 Content-Type，让浏览器自动设置
    },
    body: formData
  });
  
  return response.data;
};

// ⚠️ 错误做法：
// headers: { 'Content-Type': 'application/json' }  // ❌ 文件上传不能用JSON
```

### 2. 通知气泡

```vue
<template>
  <div class="notification-bell" @click="showNotifications">
    <i class="bell-icon"></i>
    <span v-if="unreadCount > 0" class="badge">{{ unreadCount }}</span>
  </div>
</template>

<script>
data() {
  return {
    unreadCount: 0
  }
},
mounted() {
  // 每30秒检查一次未读数量
  setInterval(this.checkUnread, 30000);
  this.checkUnread();
},
methods: {
  async checkUnread() {
    const response = await fetch('/api/notification/unread-count', {
      headers: { 'Authorization': 'Bearer ' + this.token }
    });
    this.unreadCount = response.data;
  }
}
</script>
```

### 3. 文件预览组件

```vue
<template>
  <div class="file-preview">
    <img 
      v-if="isImage(file.fileType)" 
      :src="`/api/file/${file.fileId}/preview`"
      :headers="{ 'Authorization': 'Bearer ' + token }"
    />
    <iframe 
      v-if="isPDF(file.fileType)" 
      :src="`/api/file/${file.fileId}/preview`"
    ></iframe>
  </div>
</template>

<script>
methods: {
  isImage(fileType) {
    return fileType && fileType.startsWith('image/');
  },
  isPDF(fileType) {
    return fileType === 'application/pdf';
  }
}
</script>
```

## 🔍 常见问题FAQ

### Q1: Token过期怎么办？
**A**: 收到401错误时，引导用户重新登录。建议在token过期前30分钟调用 `/user/refresh` 刷新token。

### Q2: 如何实现RTL（从右到左）语言？
**A**: 登录后根据 `i18nConfig.direction` 设置 `<body dir="rtl">`，并调整CSS样式。

### Q3: 文件下载如何处理？
**A**: 
```javascript
// 方式1：直接打开链接
window.open(`/api/file/${fileId}/download`);

// 方式2：使用fetch下载
const response = await fetch(`/api/file/${fileId}/download`, {
  headers: { 'Authorization': 'Bearer ' + token }
});
const blob = await response.blob();
const url = window.URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = fileName;
a.click();
```

### Q4: 如何判断用户是否有政务权限？
**A**: 登录响应中的 `role` 字段，如果包含"政务"则有权限。或者根据 `permissions` 数组判断。

### Q5: 申请状态有哪些？
**A**: 
- 待审核
- 处理中
- 已完成 / 已通过
- 驳回 / 已驳回
