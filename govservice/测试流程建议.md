### 阶段二：政务事项查询与申请（核心业务流程）

#### 1. 查询可用政务事项
**GET** `/api/service-item/enabled`
- 测试无参数查询（查所有启用事项）
- 测试带语言参数：`?languageType=zh-CN`
- 测试关键词搜索：`?keyword=身份证&languageType=zh-CN`
- 测试部门筛选：`?department=公安局`

#### 2. 查询事项详情
**GET** `/api/service-item/{itemId}`
- 参数：`itemId=1`
- 带语言参数：`?languageType=ug-CN`（测试维语翻译）

#### 3. 提交政务事项申请
**POST** `/api/service-item/apply`
```json
{
  "userId": 37,
  "itemId": 1,
  "applicationMaterials": "申请办理身份证，已准备相关材料"
}
```
- 记录返回的 `recordId`（如：`recordId: 1`）

#### 4. 上传申请相关文件
**POST** `/api/file/upload`
- 使用上一步返回的 `recordId`
- `fileCategory`: `ID_CARD` 或 `PROOF`

#### 5. 查询我的申请记录
**GET** `/api/service-item/applications/me`
- 测试无语言参数
- 测试带语言参数：`?languageType=zh-CN`

### 阶段六：政务人员功能测试（需要政务人员角色）

#### 17. 使用政务人员账号登录
**POST** `/api/user/login`
```json
{
  "account": "admin",
  "password": "admin123"
}
```

#### 18. 查看待处理申请
**GET** `/api/service-item/applications/pending`

#### 19. 处理申请（审批/驳回）
**PUT** `/api/service-item/applications/{recordId}/handle`
```
Params:
- status: 已通过 或 已驳回
- handleResult: 审批意见
- handleUserId: 37（政务人员ID）
```

#### 20. 创建新事项（仅政务人员）
**POST** `/api/service-item`
```json
{
  "itemName": "护照办理",
  "departmentName": "公安局",
  "handleRequirement": "需提供身份证、户口本、照片",
  "estimatedDays": 15,
  "isEnabled": true
}
```

#### 21. 启用/禁用事项
**PUT** `/api/service-item/{itemId}/status?isEnabled=false`

#### 22. 查看所有用户
**GET** `/api/user/all`

#### 23. 冻结用户
**PUT** `/api/user/{userId}/freeze?frozen=true`

## 🎯 推荐测试顺序（完整业务流程）

### 场景1：普通用户办理身份证流程
1. 注册账号 → 登录 → 查询身份证办理事项 → 提交申请 → 上传身份证照片 → 查看申请状态 → 接收通知

### 场景2：政务人员审批流程
1. 政务人员登录 → 查看待处理申请 → 查看申请人上传的文件 → 审批通过/驳回 → 系统自动发送通知给申请人

### 场景3：多语言用户流程
1. 注册维语用户 → 登录 → 切换语言为维语 → 查询事项（维语显示） → 搜索FAQ（维语） → 智能咨询（维语）
